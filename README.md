# 💪 FitnessBuddy

**Your AI Personal Trainer & Nutrition Coach built on Intercom + IntercomSwap**

FitnessBuddy combines AI-powered fitness coaching with community-driven supplement marketplace. Get personalized workouts, meal plans, and swap fitness gear/supplements through IntercomSwap - all through natural conversation with Claude.

## 🌟 Features

- **Personalized Workout Plans** - Custom routines based on your goals and experience
- **Smart Meal Planning** - Nutrition advice tailored to your calorie and macro targets
- **Progress Tracking** - Log workouts, calories, water intake, and streaks
- **Form & Technique Tips** - Proper exercise execution guidance
- **Motivational Coaching** - Stay accountable with AI encouragement
- **Supplement Marketplace** - Buy/swap/trade via IntercomSwap integration
- **Real-Time Stats** - Live dashboard with calories, workouts, and achievements
- **Streak System** - Build consistency with daily tracking

## 📦 Installation

1. Clone this repository
2. Open `interactive-demo.html` in any browser - works immediately!
3. For full AI integration, use `index.html` with your Anthropic API key

No build process, no dependencies - just pure HTML, CSS, and JavaScript.

## 🔧 Technical Details

- **Frontend**: Vanilla HTML/CSS/JavaScript
- **AI Model**: Claude Sonnet 4 via Anthropic API
- **Marketplace**: IntercomSwap protocol integration
- **Storage**: Browser localStorage for tracking
- **Data**: User stats, workout history, meal logs
